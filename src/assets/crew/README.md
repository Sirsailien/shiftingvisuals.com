# Crew pictures

Portraits for the Meet the team page go here (JPG, PNG or WebP; any size, the site
resizes them and shows them in black and white, colour on hover/tap).

1. Save the photo here, e.g. `src/assets/crew/jane-doe.jpg`
2. In that person's file in `src/content/team/`, add:

       photo: ../../assets/crew/jane-doe.jpg
